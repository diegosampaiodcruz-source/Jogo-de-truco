# Truco Brasileiro

Jogo de Truco 2x2 feito com HTML, CSS e JavaScript puro.

## Como executar
Abra `index.html` no navegador.

## GitHub Pages
1. Crie um repositório no GitHub.
2. Envie `index.html`, `style.css` e `script.js`.
3. Em Settings → Pages, selecione a branch principal e a pasta `/root`.
4. Salve e aguarde a publicação.

## Observação
A implementação usa uma versão simplificada e configurável das regras do Truco brasileiro, com manilhas pela vira, pedidos 3/6/9/12 e IA básica.
