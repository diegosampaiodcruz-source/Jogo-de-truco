Crie um jogo completo de TRUCO brasileiro para navegador, pronto para ser colocado em um repositório do GitHub e executado pelo GitHub Pages.

O projeto deve ser desenvolvido usando HTML5, CSS3 e JavaScript puro, sem depender de frameworks obrigatórios.

IMPORTANTE:
O jogo deve ser realmente funcional e jogável, e não apenas uma interface visual.

==================================================
2. VISUAL DO JOGO
==================================================

Criar uma mesa de Truco com aparência moderna e profissional.

A mesa deve ser:

- verde de feltro;
- formato oval;
- borda de madeira;
- iluminação suave;
- sombras;
- aparência de mesa real;
- cartas com aparência física;
- animações suaves.

O jogo deve funcionar bem em:

- computador;
- notebook;
- tablet;
- celular.

Utilizar layout responsivo.

==================================================
3. CARTAS EM SVG
==================================================

Todas as cartas devem utilizar SVG.

NÃO utilizar imagens rasterizadas para representar as cartas.

Cada carta deve ter:

- fundo branco;
- bordas arredondadas;
- número/letra no canto superior;
- número/letra no canto inferior invertido;
- naipe;
- símbolo grande no centro;
- cores corretas para os naipes;
- aparência profissional;
- sombra;
- animação ao selecionar.

As cartas devem ser vetoriais e permanecer nítidas em qualquer resolução.

Criar SVGs individuais para todas as cartas.

==================================================
4. BARALHO
==================================================

Utilizar um baralho de Truco com 40 cartas:

Ouros:
A, 2, 3, 4, 5, 6, 7, Q, J, K

Espadas:
A, 2, 3, 4, 5, 6, 7, Q, J, K

Copas:
A, 2, 3, 4, 5, 6, 7, Q, J, K

Paus:
A, 2, 3, 4, 5, 6, 7, Q, J, K

Embaralhar as cartas antes de cada rodada.

Nunca repetir uma carta dentro da mesma rodada.

==================================================
5. JOGADORES
==================================================

Utilizar quatro jogadores:

1. VOCÊ
2. SEU PARCEIRO
3. ADVERSÁRIO 1
4. ADVERSÁRIO 2

A mesa deve representar uma partida de Truco em duplas.

IMPORTANTE:

SEU PARCEIRO DEVE FICAR EXATAMENTE À SUA FRENTE.

Layout:

              ADVERSÁRIO 1

              SEU PARCEIRO

ADVERSÁRIO 2                    ADVERSÁRIO 3

                   VOCÊ

A posição deve ficar visualmente clara.

==================================================
6. CARTAS DO JOGADOR
==================================================

O jogador deve receber 3 cartas.

As três cartas devem ficar na parte inferior da tela.

As cartas devem ficar levemente sobrepostas, formando uma mão bonita.

Ao passar o mouse sobre uma carta:

- levantar a carta;
- aumentar levemente;
- adicionar sombra;
- destacar a carta.

No celular:

- permitir toque na carta.

==================================================
7. UM CLIQUE PARA JOGAR
==================================================

IMPORTANTE:

O jogador deve conseguir jogar uma carta com APENAS UM CLIQUE.

Não criar botão separado "Jogar carta".

Ao clicar na carta:

1. A carta sai da mão;
2. A carta é animada até o centro da mesa;
3. A carta permanece visível na mesa;
4. A vez passa para o próximo jogador.

Não exigir confirmação.

==================================================
8. CARTAS JOGADAS
==================================================

TODAS as cartas que forem jogadas devem permanecer VISÍVEIS.

Não esconder cartas jogadas.

A mesa deve mostrar claramente:

- carta do adversário 1;
- carta do parceiro;
- carta do adversário 2;
- sua carta.

As cartas jogadas devem permanecer no centro da mesa até o final da rodada/vaza.

Usar animação de entrada.

==================================================
9. CARTA VIRA
==================================================

A carta VIRA deve ficar visível durante a rodada.

Colocar a VIRA em uma área bem identificada.

Exemplo:

       VIRA
       [ carta ]

A VIRA deve utilizar o mesmo sistema SVG das demais cartas.

Mostrar claramente qual carta é a VIRA.

==================================================
10. MANILHAS
==================================================

Implementar corretamente a lógica de manilhas do Truco.

A manilha deve ser determinada pela carta VIRA.

As quatro cartas imediatamente superiores à VIRA na ordem do baralho devem ser as manilhas.

A ordem das manilhas deve ser:

Paus
Copas
Espadas
Ouros

A lógica de comparação das cartas deve respeitar as regras do Truco.

==================================================
11. VEZ DOS JOGADORES
==================================================

Mostrar claramente de quem é a vez.

Exemplo:

" SUA VEZ "

ou

" PARCEIRO JOGANDO "

ou

" ADVERSÁRIO JOGANDO "

Destacar visualmente o jogador da vez.

==================================================
12. IA
==================================================

Os adversários devem jogar automaticamente.

IMPORTANTE:

A IA NÃO DEVE JOGAR RÁPIDO DEMAIS.

Criar atraso natural entre as jogadas.

Exemplo:

Jogador:
joga imediatamente.

IA:
espera aproximadamente 1,5 a 3 segundos.

O parceiro também deve esperar antes de jogar.

Adicionar pequenas variações aleatórias no tempo.

As jogadas devem parecer humanas.

==================================================
13. INTELIGÊNCIA DA IA
==================================================

A IA deve considerar:

- força da carta;
- manilha;
- cartas já jogadas;
- rodada atual;
- valor do Truco;
- possibilidade de ganhar a vaza.

Não fazer a IA simplesmente escolher uma carta aleatória.

Criar uma estratégia básica.

==================================================
15. PLACAR
==================================================

O placar deve ficar no:

CANTO SUPERIOR ESQUERDO.

Nunca colocar o placar no centro da mesa.

Exemplo:

┌─────────────────────────┐
│ VOCÊ + PARCEIRO   5     │
│ ADVERSÁRIOS       3     │
└─────────────────────────┘

O placar deve ficar sempre visível.

No celular deve continuar acessível sem atrapalhar as cartas.
